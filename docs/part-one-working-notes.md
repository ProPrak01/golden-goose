# Part One Working Notes

> These are the applicant's unedited working notes. They are not the final positioning statement or vision document.

## Remember

- Course names and schedule (lectures, labs)
- Assignment/quiz deadlines
- Marks/scores received
- Explicitly stated reason for a good/bad result ("rushed it," "didn't understand the topic," "studied the wrong chapter")
- Stated study preferences ("I need more time on numericals than theory")
- A past instance of procrastination or rushing tied to a specific course/task
- Which topics within a course you've said you're weak/strong in
- Recurring patterns you've explicitly pointed out yourself ("I always do this before midterms")

## Remember only with clear evidence (explicit statement required)

- A specific mark/score — only if you stated the number
- A reason for performance — only if you said the reason, not inferred from score alone
- A deadline — only if date/course was clearly mentioned
- A "lesson learned" — only if you framed it as one ("next time I should...")

## Ignore

- One-off venting ("this professor is annoying")
- Hypotheticals ("maybe I'll start tomorrow")
- Small talk unrelated to academics
- Jokes or sarcasm about coursework
- Non-academic personal events unless you tie them to academic impact

## Never infer

- Emotional state from tone of voice or word choice
- Motivation or laziness from a single missed deadline
- Confidence/competence from one score
- Any conclusion about you as a student/person not explicitly stated by you

## Show the user (when Kivi recommends something)

- The specific past statement(s) it's drawing from
- The date/source of that statement
- A confidence/certainty indicator if evidence is thin
- Which course/assignment it's tied to

## Let the user change

- Correct a wrong deadline/mark
- Delete a memory entirely
- Mark something as "no longer relevant" without deleting (soft-expire)
- Override/dismiss a suggestion permanently for that topic

## Ask before acting (instead of assuming)

- Vague plans ("I'll study later this week")
- Ambiguous course references (two courses with similar names)
- Old data that might be stale (last semester's pattern applied to this semester)
- Conflicting signals (you said you're "fine" but also said you rushed something)

## Product direction

Kivi should remember my everyday schedule of college classes and assignment submissions and marks I got, like a personal teacher.

That helps because students forget when to start preparing for a quiz or an assignment submission. They often do last-minute work, which hides their creativity, and they forget the past: if something bad happened in a quiz for a reason, someone should remember and remind you when doing the next related work.

It must not infer or retain my emotions when talking or unnecessary talks with it.

The user stays in control through confirmation and visibility.

Therefore, my product will let Hey Kivi tell my next course of actions for today in academics.
