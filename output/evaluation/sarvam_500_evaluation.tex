\section*{Executive summary}
This report analyses 500 stored Sarvam extraction calls. Every completed record retains raw ASR, formatted text, metadata, parsed extraction, raw provider payload, policy outcome, evidence check, latency, and token use. The exact policy match rate is 81.2\% (406/500). The result is useful but \textbf{not} submission-ready as a safety claim: inferred-trait and uncertain-detail cases require a stricter prompt and policy validation pass.

\section*{Interpretation and action}
The model reliably retained explicit deadlines and preferences. It was weaker on explicit episodes, and it over-retained 50 inferred-trait prompts that should have been rejected. It also converted uncertain details into acceptance or rejection instead of clarification. Before relying on provider-assisted automatic suggestions more broadly, strengthen the extraction prompt, add category-specific adversarial tests, and reject candidate statements whose source explicitly denies the inferred label.
\begin{enumerate}
  \item Tighten extraction instructions around explicit negations, for example: ``do not label me as lazy.''
  \item Create a first-class \emph{clarify} route for incomplete or stale details rather than forcing a retention decision.
  \item Investigate the six non-verbatim evidence spans and add regression tests for each failure mode.
\end{enumerate}
